K-Token Saver v3.6 · 공식 웹 사용자 설명서

📖 기능별 사용자 설명서 (어떤 기능이고, 어떻게 동작하나요?)

K-Token Saver는 ChatGPT · Claude · Gemini 입력창 우측 하단 플로팅 위젯과 브라우저 상단 팝업 대시보드 두 곳에서 100% 브라우저 내부(<1ms)로 동작합니다.

⚡ Chrome 웹 스토어 무료 설치 ← 공식 소개 페이지로 🎯 시너지 프롬프트 북 ↗
🚀 3단계 빠른 시작 📚 기능별 상세 안내 (8종) ⌨️ 단축키 빠른 참조

🚀 3단계 빠른 시작

STEP 1 · 입력

평소처럼 한국어로 적기

구어체·메신저 복사본·코드블록이 섞인 질문도 그대로 AI 채팅창이나 팝업 입력칸에 적습니다.

STEP 2 · 정리 (선택)

✨ 다듬기 Alt+Shift+P

비교 카드로 오타·구어체·띄어쓰기를 먼저 정리하고, 표준/간결/격식 톤을 고른 뒤 ✅ 적용합니다.

STEP 3 · 구조화 전송

⚡ 변환 Alt+Shift+K

군더더기를 빼고 핵심 과업·배제 조건을 분리해 변환합니다. 실수했다면 Alt+Shift+Z로 즉시 원문 복구됩니다.

📚 기능별 상세 사용자 설명서

기능 1 · 무료 무제한

✨ 문장 다듬기 비교 카드 (Alt+Shift+P)

Q. 어떤 기능인가요?

거친 한국어·메신저 타임스탬프([오후 2:14] 김철수:)·자주 틀리는 띄어쓰기·구어체를 100% 브라우저 오프라인 사전으로 교정하고, 적용 전에 원문과 비교·편집할 수 있는 미리보기 카드입니다.

Q. 어떻게 동작하고 사용하나요?

① 입력창을 바로 덮어쓰지 않고 우측 상단 비교 카드만 엽니다. ② ✨ 표준 / ⚡ 간결 / 💼 격식 버튼을 누르면 네트워크 호출 없이 즉시 문체를 바꿉니다. ③ 의심 단어는 🙈 오타 아님으로 보호 등록하거나, 카드를 직접 수정해 ✅ 적용(Ctrl+Enter)하면 다음부터 자동 학습됩니다. ④ AI 문맥 재작성이 필요하면 🤖 AI 교정으로 현재 채팅 AI에게 안전하게 교정을 맡길 수 있습니다.

기능 2 · 무료 무제한

⚡ 프롬프트 변환 (Alt+Shift+K) & ↩ 복구 (Alt+Shift+Z)

Q. 어떤 기능인가요?

길고 두서없는 한국어 질문을 AI가 딴소리 없이 정확하게 답하도록 구조화 규격([CORE_TASK], STRICT_EXCLUSION, [OUTPUT])으로 1ms 이내에 압축·정렬합니다.

Q. 어떻게 동작하고 사용하나요?

① 단, ~제외 / ~빼고 표현은 자동으로 STRICT_EXCLUSION에 격리되고, ```코드블록```은 100% 원형 보존됩니다. ② 변환 직후 위젯의 ✨ 다듬기 버튼은 ↩ 초기화로 바뀌어 1클릭 원문 복구가 가능하며, Alt+Shift+Z는 단계별로 최대 5단계까지 되돌립니다. ③ AI에 전송(Enter)해 입력창이 비워지면 자동으로 다시 ✨ 다듬기 상태로 풀립니다.

기능 3 · Free vs Pro

🗜️ 초압축 vs 👑 팀장지휘 · 💻 코드 · 📐 수식

Q. 각 모드는 무엇이 다른가요?

🗜️ 초압축(Free 무제한)은 태그 오버헤드를 최소화해 깔끔하게 과업·배제 조건만 압축합니다. 👑 팀장지휘 / 💻 코드 / 📐 수식(Pro)은 질문 성격(장애 분석, 구현, 아키텍처, 비교, 수식·증명 등) 28종을 자동 판별해 전문 지휘 구조와 도메인별 심층 검증선(PRO_VERIFY), 직무 스키마 팩 5종(CISO·FinOps·Deal Desk·ITSM·DPA)을 자동 결합합니다.

Q. 어떻게 사용하나요?

위젯이나 팝업 상단 칩을 눌러 전환합니다. 무료 사용자는 🗜️ 초압축을 제한 없이 쓰며, 팝업 오프라인 독립 변환기에서도 다른 사이트(메일·메모장 등)에 붙여넣을 변환문을 미리 만들어 📋 복사할 수 있습니다.

기능 4 · 개인 사전

📚 내 용어·사전 학습 & 고유명사 보호

Q. 자동 교정 학습과 고유명사 보호는 어떻게 다른가요?

팝업 📚 내 용어·사전 학습 & GitHub 제안에서 두 가지를 명확히 나눠 관리합니다.
• ✏️ 자동 교정 학습(오타→바른말): 등록한 단어가 나오면 다듬기 시 지정한 바른말로 자동 치환합니다(예: 빠레 → 빨리).
• 🛡️ 고유명사 보호(단일 용어): 사내 프로젝트명·신조어를 오타로 의심([확인 필요])하거나 건드리지 않도록 교정에서 제외합니다.

Q. 백업 및 도메인 사전 팩 추가는 어떻게 하나요?

💾 백업 저장 / 📥 JSON 불러오기로 도메인별 사전 팩 3종을 재설치 없이 즉시 병합하거나 PC 간 옮길 수 있습니다.

기능 5 · 선택 연결 (기본 OFF)

🧠 AI 정밀 다듬기 (BYOK · 로컬 Ollama)

Q. 기본 동작에서도 외부 서버로 전송되나요?

아니요. 기본값은 완전히 꺼져(OFF) 있어 외부 전송이 0건입니다. 사용자가 팝업에서 체크박스를 직접 켜고 본인의 API 키(Google Gemini 또는 HTTPS OpenAI 호환 API)나 내 PC의 로컬 Ollama(127.0.0.1)를 입력한 경우에만 Service Worker에서 안전하게 호출합니다.

Q. 어떻게 안전하게 동작하나요?

🛡️ 전송 전 보호가 켜져 있으면 API 키·이메일·URL·코드블록을 임시 자리표시자로 가린 뒤 AI에게 다듬기만 요청하고, 응답을 받은 뒤 내 PC에서 원본을 다시 복원합니다. Ollama 사용 시에는 터미널 환경변수 OLLAMA_ORIGINS=* 설정 후 실행해야 합니다.

기능 6 · Team DLP

🛡️ 전송 전 로컬 DLP 민감정보 마스킹

Q. 어떤 기능인가요?

실수로 AWS 키, OpenAI/Slack API 키, JWT, 이메일, 휴대폰·주민번호, 사내 비공개 IP·도메인을 AI에 붙여넣었을 때 브라우저 밖으로 나가기 전에 [REDACTED_API_KEY_1], [REDACTED_CORP_DOMAIN_1] 형태로 가려주는 기능입니다.

Q. 어떻게 사용하고 복구하나요?

Team 라이선스 인증 후 팝업 하단에서 전송 전 로컬 DLP를 켜고, 가릴 사내 도메인(예: corp.internal)을 쉼표로 적어두면 변환과 동시에 자동 치환됩니다. Alt+Shift+Z를 누르면 입력했던 원문 그대로 복구되며, 팝업 이력에도 실제 비밀키는 남기지 않습니다.

기능 7 · Pro / Team

☁️ 다기기 설정 동기화 & 📊 FinOps 리포트

Q. 다기기 설정 동기화는 무엇을 어떻게 동기화하나요?

팝업 내 로컬 상시 배제 규칙(예: 서론 제외, 추측 금지)을 여러 PC에서 매번 다시 적지 않도록, ☁️ 다기기 설정 동기화를 켜면 동일한 Google 계정으로 로그인된 Chrome 브라우저끼리 chrome.storage.sync로 배제 규칙을 자동 병합·동기화합니다(프롬프트 원문은 동기화하지 않습니다).

Q. FinOps 리포트는 어디에 쓰나요?

누적 절감 토큰·환산 절감액(KRW)과 최근 변환 통계(최대 80건 로컬 보관)를 📊 FinOps CSV(Excel 호환 UTF-8 BOM) 또는 🧾 JSON 리포트로 내려받을 수 있습니다.

기능 8 · 위젯 · 제보

🧩 플로팅 위젯 조작 & 🧪 익명 패턴 제보

Q. 위젯이 입력창을 가리거나 이동하고 싶을 땐 어떻게 하나요?

위젯 왼쪽 점 6개 핸들을 끌어 원하는 위치로 옮기면 새로고침 후에도 위치가 기억됩니다. — 버튼으로 미니 접기를 켤 수 있고, 위젯이 AI 입력창과 겹치면 하단 제휴 바가 자동으로 숨겨집니다. 무료 버전 하단 배너의 ✕를 누르면 12시간 동안 숨겨집니다(Pro/Team은 영구 비노출).

Q. 🧪 패턴 제보는 안전한가요?

문장 다듬기 카드에서 🧪 패턴 제보를 누르면 이메일·계좌·전화번호·이름·비밀키·큰 숫자를 {EMAIL}, {PERSON}, {SECRET} 등으로 비식별 치환한 미리보기를 먼저 보여줍니다. 내용을 확인한 뒤 직접 GitHub 패턴 제보 열기를 눌렀을 때만 등록 양식이 열립니다.
